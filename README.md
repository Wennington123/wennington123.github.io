# Wennington Dias Aquino - Portfólio

Meu portfólio pessoal como desenvolvedor frontend, pedagogo e mestrando em ensino.

## Sobre

Este projeto é meu portfólio pessoal, construído com HTML, CSS e JavaScript puro — sem frameworks, sem dependências externas pesadas. É um site estático simples, limpo e rápido, hospedado no GitHub Pages.

## Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com variáveis CSS, Grid e Flexbox
- **JavaScript ES6+** - Interatividade (tema claro/escuro, animações, filtros)
- **GitHub Pages** - Hospedagem

## Funcionalidades

- ✅ Design responsivo (mobile-first)
- ✅ Tema claro/escuro com persistência local
- ✅ Efeito de digitação no hero
- ✅ Filtro de projetos por categoria
- ✅ Animações de scroll suaves
- ✅ Navegação com destaque da seção ativa
- ✅ Menu mobile com hamburger

## Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Wennington123/wennington123.github.io.git
   ```

2. Abra o `index.html` no seu navegador ou use um servidor local:
   ```bash
   # Com Python
   python3 -m http.server 8000
   
   # Com Node.js
   npx serve .
   ```

3. Acesse `http://localhost:8000`
