# Wennington Dias Aquino - Portfólio

Portfólio pessoal — uma landing page simples e direta, com foco nas informações: quem sou, o que faço e onde me encontrar.

🌐 [Acesse o portfólio](https://wennington123.github.io/)

## Sobre

Site estático de **um arquivo só** (`index.html`): HTML + CSS embutido, sem JavaScript, sem frameworks, sem dependências externas. Fontes do sistema e dark mode automático via `prefers-color-scheme`.

## Estrutura

```
wennington123.github.io/
├── index.html   # Página completa (HTML + CSS)
└── README.md
```

## Como rodar localmente

Basta abrir o `index.html` no navegador. Se preferir um servidor local:

```bash
python3 -m http.server 8000
# ou
npx serve .
```

## Deploy

Hospedado no GitHub Pages — qualquer push no branch `main` publica automaticamente.
